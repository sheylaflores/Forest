# Robust Demand Forecasting for Critical Products in the Fishing Sector

## Project Overview

This project delivers a robust demand forecasting solution for 20 critical products within the "Hidráulica Componente" business line, which serves the Peruvian fishing industry. The primary objective is to generate a reliable 6-month demand forecast (November 2025 - April 2026) to support inventory management and strategic planning.

The forecasting challenge is characterized by high volatility and strong seasonality, driven by the Peruvian Anchoveta (CHI) fishing seasons. To address this, the project employs a multi-model approach, comparing SARIMA, Prophet, and XGBoost to identify the best forecasting model for each individual product.

## Methodology

The forecasting process is implemented in a single, automated Python script (`src/demand_forecasting.py`) that covers the entire workflow from data preprocessing to the generation of final deliverables.

### 1. Data Preprocessing and Feature Engineering

- **Data Loading**: The script loads the historical consumption data from `data.xlsx`, parsing dates and aggregating monthly totals for each product to resolve any duplicate entries.
- **Handling Intermittency**: A continuous time series is created for each product from January 2022 to October 2025. Any missing monthly data is imputed with zero, a common practice for intermittent demand patterns.
- **Feature Engineering**: To capture the strong seasonality of the fishing industry, two binary features were engineered:
    - `temporada_pesca`: Flags the primary fishing season months (April, May, June, November, December).
    - `pico_pre_temporada`: Flags the months with pre-season demand peaks (February, March, September, October).

### 2. Modeling Strategy

A comparative modeling approach was adopted to ensure the most accurate forecast for each product.

- **Data Partitioning**: The historical data was split into a training set of 37 months and a validation set of 9 months, adhering to a strict chronological order.
- **Model Training**: Three distinct time-series models were trained for each of the 20 products:
    1.  **SARIMA**: A statistical model that captures both trend and seasonality.
    2.  **Prophet**: A robust forecasting model developed by Facebook, designed to handle seasonality and holidays effectively.
    3.  **XGBoost**: A powerful gradient-boosting model that leverages the engineered features and historical lags to make predictions.
- **Model Selection**: The best model for each product was selected based on the **Mean Absolute Percentage Error (MAPE)** on the validation set, as it provides a clear and interpretable measure of forecast accuracy.

## Analysis of Results

The multi-model approach proved effective, with different models excelling for different products, confirming that a one-size-fits-all approach is suboptimal for this diverse set of items.

## Deliverables

The project generated the following deliverables, located in the `/output` directory:

1.  **Error Summary (`error_summary.xlsx`)**: An Excel file containing a detailed comparison of the RMSE, MAE, and MAPE for all three models across the 20 products on the validation set.
2.  **Demand Forecast (`demand_forecast.xlsx`)**: An Excel file with the final 6-month demand forecast for each product, generated by its best-performing model.
3.  **Robust Plots**:
    -   **Validation Plots**: Visual comparisons of the actual vs. predicted demand for the top 5 products.
    -   **Forecast Plots**: Projections of future demand for the top 5 products, including confidence intervals.
    -   **Absolute Error Plots**: Monthly absolute error for the top 5 products, providing insight into model performance over time.

## Conclusion

This project successfully delivered a robust and automated demand forecasting solution tailored to the unique challenges of the fishing sector. By leveraging a multi-model approach and incorporating domain-specific knowledge through feature engineering, we have produced reliable forecasts that can significantly improve inventory planning and decision-making. The generated deliverables provide a clear and comprehensive view of the expected demand, empowering the business to prepare for future market needs.
